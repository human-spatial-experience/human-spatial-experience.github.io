# Embedding Human Spatial Experience in AI-Aided Architectural Design — CHI 2027 Workshop

Workshop website: https://human-spatial-experience.github.io/

## Deploy (GitHub Pages)
1. Create a GitHub organization named `human-spatial-experience` (free plan).
2. In it, create a public repo named exactly `human-spatial-experience.github.io`.
3. Upload `index.html` (and this README) to the `main` branch.
4. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
5. Site is live at https://human-spatial-experience.github.io/ within a few minutes.
Invite co-organizers to the org so they can edit.
